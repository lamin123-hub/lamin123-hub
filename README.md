### ♟️ Machine Learning Meets Chess

*Can we teach computers to make better decisions, one chess move at a time?*

As part of UIC's **Mathematics Undergraduate Research Lab**, I'm exploring how different search algorithms perform across chess positions.

My work involves:

- Implementing **Minimax** and **Monte Carlo Tree Search**
- Comparing algorithm performance and decision-making
- Investigating how search depth and computational limitations influence results

Basically, I get to combine chess, mathematics, and AI research. Pretty cool.
